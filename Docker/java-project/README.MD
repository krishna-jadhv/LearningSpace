# Java Simple Calculator

A lightweight command-line Java application that takes two numbers from the user and calculates their sum and product.

---

## Prerequisites

- **Java Development Kit (JDK)** version 8 or higher installed on your system.
- Terminal, Command Prompt, or PowerShell.
